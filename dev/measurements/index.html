Measurements and output

Measurements are taken during a run, while the population is in memory, because the tree later loses extinct lineages. A MeasurementSpec says what to record, a MeasurementAccumulator records it while simulate! runs (of a block or a schedule), and finalize_measurements returns a Measurements with two plain vectors, trajectory and snapshots. Plain structs and NamedTuples: a Vector{NamedTuple} is already a Tables.jl table, and no file is written.

using ClonalEvolutionTx, Random

base = BirthDeathBlock(birth = s -> 1.0, death = s -> 0.5, μ = 1.0,
                       response = LinearResponse(4.0),
                       mutations = [Resistance(ν = 0.01, α = 0.8)])

spec = MeasurementSpec(
    trajectory_dt = 1.0,
    triggers      = [AtTime(4.0), AtSize(400), AtBlockEnd()],
    stats         = [popsize, MeanBurden(), n_resistant],
)
acc = MeasurementAccumulator(spec)
pop = initialize_population(1)
simulate!(pop, remake(base; stop_above = 800, restart_on_extinction = true), Xoshiro(2);
          accumulator = acc)
meas = finalize_measurements(acc)

[(sn.trigger, round(sn.t, digits = 2), sn.N) for sn in meas.snapshots]
3-element Vector{Tuple{AbstractTrigger, Float64, Int64}}:
 (AtTime(4.0), 4.0, 1)
 (AtSize(400, :up, false), 17.38, 400)
 (AtBlockEnd(), 18.79, 800)

Triggers (when)

triggersemantics
AtTime(t)the state exactly at the absolute time t: after every event at or before t, before any later one. Fires once; t == tmax fires at the end of that block. An AtTime before the population's current time throws, since that state is gone
AtSize(N; direction = :up, every = false)first (or every) arrival at size N from below (:up), above (:down) or either side
Every(Δt)full snapshots on the grid t₀ + kΔt
When(f; every = false)when f(pop) returns true, checked at block start and after each event; keep it cheap
AtBlockEnd()at the end of every block, whatever ended it. Treatment switches are block ends

trajectory_dt = Δt in the spec adds cheap TrajectoryPoints on the time grid t₀ + kΔt (t₀ is the time at which the accumulator first starts a block). With trajectory_clone_sizes = true each point also carries the sizes of all living clones.

Measurements record the state exactly at the measurement time: the clock pop.t that statistics see equals the item's time, and the recorded drug level m is the dose's level at that time (for a TimeDose, the level m(t) itself). At one instant, time items come first, then AtSize/When, then AtBlockEnd.

One accumulator can be carried across blocks and schedules: its grids continue, each one-shot trigger fires at most once, and trigger firing does not repeat across chained blocks. Grid times that pass while the population is simulated without the accumulator are skipped.

What is recorded

A trajectory point has t, N, the drug level m, n_sensitive (cells in clones with α == 1), n_resistant (all other cells) and optionally clone_sizes.

p = meas.trajectory[end]
(p.t, p.N, p.n_sensitive, p.n_resistant, p.m)
(18.0, 580, 508, 72, 0.0)

A snapshot has t, N, m, the trigger, the index block of the block in the population's log, its label, the requested statistics stats as a NamedTuple, and samples (see Sampling), with stats = nothing for a sample size larger than the population.

sn = meas.snapshots[1]
(sn.label, sn.stats.popsize, round(sn.stats.mean_burden, digits = 1), sn.samples)
("block", 1, 1.0, NamedTuple[])

Statistics (what)

An entry of stats is

  • a statistic type: SFS, MutationsPerCell, MeanBurden, CloneSizes, MutationFrequencies, HillNumbers, SFSHillNumbers, Divisions, SensitiveResistant;
  • a named function pop -> value, such as popsize or n_resistant, keyed by its name;
  • or a pair :name => f for anything else.

Anonymous functions are rejected (they have no usable key): write :name => (pop -> ...) instead. Two statistics with the same name are an error. A new statistic type subtypes AbstractStatistic and defines measure(stat, pop) and, optionally, statistic_name(stat).

n_big_clones(pop) = count(>(50), clone_sizes(pop))
spec2 = MeasurementSpec(triggers = [AtBlockEnd()],
                        stats = [SFS(), :resistant_fraction => (pop -> n_resistant(pop) / popsize(pop)),
                                 n_big_clones])
keys(measure(pop, spec2.stats))
(:sfs, :resistant_fraction, :n_big_clones)

Direct measurement

measure(pop, stats) evaluates a vector of statistics between simulate! calls and returns a NamedTuple. It never changes the population.

measure(pop, [popsize, MeanBurden(), HillNumbers(q = [0, 1, 2])])
(popsize = 800, mean_burden = 24.245, hill_numbers = [27.0, 1.8916424714243605, 1.2829147823855822])

The treatment log

Every population carries a log with one BlockSummary per simulated block: label, t_start, t_end, end_reason, ticks, accepted events, restarts, the dose description and the final drug level. Figures that shade treatment periods read it.

[(b.label, b.dose, b.end_reason) for b in pop.log]
1-element Vector{Tuple{String, String, Symbol}}:
 ("block", "fixed m = 0.0", :above)

Measuring across a schedule

sched = AdaptiveOnOff(base; N_low = 400, N_up = 800, N_prog = 1_600, t_max = 3.0)
acc2 = MeasurementAccumulator(MeasurementSpec(trajectory_dt = 0.5, triggers = [AtBlockEnd()],
                                              stats = [popsize, n_resistant]))
simulate!(pop, sched, Xoshiro(2); accumulator = acc2)
m2 = finalize_measurements(acc2)
(schedule_outcome(pop), length(m2.trajectory), [(s.label, s.stats.popsize) for s in m2.snapshots])
(:tmax, 7, [("AT on", 400), ("AT off", 800), ("AT on", 400), ("AT off", 709)])

Samples larger than the population, and errors

A snapshot of a population smaller than a requested sample size n (for example the AtBlockEnd snapshot of a block that ended in extinction) records (n = n, stats = nothing) for that size: no sample is drawn, and the other sizes are drawn with their usual seeds. Invalid triggers, statistics or spec options throw at construction.
