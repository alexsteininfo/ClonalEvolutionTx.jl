ClonalEvolutionTx.AbstractResponse — Type
AbstractResponse

Drug response D(m): the extra death rate per unit of resistance trait α at treatment level m ∈ [0, 1] (SPEC §4.2). A subtype must define drug_death and may define inverse_drug_death; D must be monotone non-decreasing on [0, 1] with D(0) = 0. Without an inverse, a bisection fallback (which relies on exactly that assumption) is used.

ClonalEvolutionTx.AdaptiveOnOff — Type
AdaptiveOnOff(base; N_low, N_up, N_prog, t_max, m = 1.0)

Adaptive therapy: "AT on" (FixedDose(m)) until N falls to N_low (N ≤ N_low), then "AT off" (no drug) until N reaches N_up (N ≥ N_up), repeated until progression (N_prog), extinction or t_max. Requires 1 ≤ N_low < N_up < N_prog and a finite t_max (ArgumentError). Counterpart of manuscript_v1's adaptive therapy (BirthDeathMutation_AT's adaptiveprocess!). t_max is measured from the schedule start.

ClonalEvolutionTx.AtBlockEnd — Type
AtBlockEnd()

Snapshot at the end of every block, whatever ended it (a stop, tmax or extinction). Treatment switches are block ends, so in a schedule this marks every toggle.

source
ClonalEvolutionTx.AtSize — Type
AtSize(N; direction = :up, every = false)

Snapshot when an accepted event brings the population size to N from direction: :up (arrival from below), :down (arrival from above) or :either. A population that already sits at N when the accumulator first sees it has not arrived there. Fires once per accumulator, or at every arrival with every = true. If the population was simulated without the accumulator between two of its blocks, the change from the size it last saw to the size at the next block start counts as one step. Requires N ≥ 0 (N ≥ 1 for :up).

source
ClonalEvolutionTx.AtTime — Type
AtTime(t)

Snapshot of the state exactly at the absolute time t: after every event at or before t and before any later one. Fires once per accumulator; t equal to a block's tmax fires at the end of that block. An AtTime that lies before the population's time when the accumulator starts a block throws ArgumentError there (that state is gone). t must be finite.

ClonalEvolutionTx.BirthDeathBlock — Type
BirthDeathBlock(; birth, death, birth_density = Returns(1.0), death_density = Returns(0.0),
                response = LinearResponse(0.0), dose = FixedDose(0.0), μ = 0.0,
                mutations = (), stop = Returns(false), stop_above = typemax(Int),
                stop_below = -1, tmax = Inf, restart_on_extinction = false,
                max_clones = typemax(Int), label = "block")

One stretch of birth–death dynamics with fixed rules, simulated by simulate!.

  • birth, death: functions s -> β(s) and s -> δ(s) of a clone's selection trait.
  • birth_density, death_density: functions N -> B(N) and N -> C(N) of the population size, common to all clones: B(N) multiplies every birth rate and C(N) is added to every death rate, so a cell of a clone with traits (s, α) has birth rate b = β(s)·B(N) and death rate d = δ(s) + C(N) + α·D(m).
  • response: how the drug level raises death (see LinearResponse, HillResponse).
  • dose: how the drug level m is set (see FixedDose and the other doses).
  • μ: mean number of neutral mutations per daughter per division (Poisson), μ ≥ 0.
  • mutations: the mutation kinds (Drivers, Resistance, CustomMutation) as a tuple or vector, applied to each daughter in list order.
  • stop: a function of the population; the block ends as soon as it returns true.
  • stop_above, stop_below: the block ends when the population size reaches stop_above (N ≥ stop_above) or falls to stop_below (N ≤ stop_below).
  • tmax: the absolute simulation time at which the block ends (not a duration); Inf for none, never NaN.
  • restart_on_extinction: restart from the state at the start of the block if the population dies out.
  • max_clones: no new clone is created once this many clones exist (≥ 1).
  • label: name recorded in the population's log.

Throws ArgumentError for μ < 0, isnan(tmax), an entry of mutations that is not an AbstractMutation, or max_clones < 1. Use remake to change fields.

source

ClonalEvolutionTx.CellNode — Type
CellNode

A handle on one node of a LineageTree: the tree, the cell's id, and the node's index at the time the handle was made. Read the cell through properties:

propertyvalue
node.id, node.birthtime, node.clonethe cell's id, birth time, clone index
node.neutral, node.totalits own and its root-to-cell neutral mutation count
node.parent, node.left, node.rightCellNode or nothing
node.dataall of the above as a TreeCell

Handles stay valid while the tree changes, also across compaction (the index is looked up again by id when it has moved). Do not read a handle on a cell that has died and been pruned: it may still return the old values or throw, depending on whether the row has been compacted away yet; check with isalive first. Handles taken during an attempt that ends in an extinction restart are invalid as well: the restart reuses those ids for new cells, so do not keep handles across a simulation that may restart. Two handles are == when they name the same cell of the same tree. The AbstractTrees interface is implemented, so Leaves(node), PreOrderDFS(node) and print_tree(node) work; the package's own statistics do not need them and are much faster.

ClonalEvolutionTx.CloneTable — Type
CloneTable()

Clone-level state of a population, stored as struct-of-arrays. Clones are numbered in order of creation (parent == 0 marks a founder clone) and are never removed, so the history of extinct clones is kept. Per clone: s, α, kind (:founder | :driver | :resistance | :custom), origin_time, origin_cell, size, and the cached rates β, δ. The living list alive (with alive_pos, 0 when not living), the maxima maxβ, maxδ, maxα over living clones (0.0 if none) and the running sums sumNβ = Σ Nₖβₖ, sumNδ, sumNα give the simulation loop its exact O(1) rate bound and dose level.

ClonalEvolutionTx.CustomDose — Type
CustomDose(base, dose::AbstractDose; N_prog, t_max = Inf)

One block labelled "custom dose" run with any dose (typically a SizeDose m(N) or TimeDose m(t)) until progression, extinction or t_max. The block starts at the schedule start, so a TimeDose measures time from the schedule start. No manuscript_v1 counterpart (an extension). t_max is measured from the schedule start. With the default t_max = Inf a run that can neither reach N_prog nor die out (for example one held below N_prog by its density dependence) never ends: give a finite t_max unless progression or extinction is certain.

ClonalEvolutionTx.Drivers — Type
Drivers(; ν, Δs, update = :additive)

Driver mutations: with probability ν per daughter per division the child's s changes by Δs (a number or univariate distribution, drawn per mutation); α is untouched. update is :additive (s′ = s + Δs), :multiplicative (1 + s′ = (1 + s)(1 + Δs)) or a function (s, Δs) -> s′.

ClonalEvolutionTx.LineageTree — Type
LineageTree()

The nodes of one or more lineage trees, stored column-wise: node i has parent[i], left[i], right[i] (indices, 0 for none), and the cell's id[i], birthtime[i], clone[i] (its clone index), neutral[i] (neutral mutations acquired at its birth) and total[i] (neutral mutations on the whole path from its root, including its own).

ClonalEvolutionTx.MeasurementAccumulator — Type
MeasurementAccumulator(spec::MeasurementSpec)

Records what spec asks for while simulate! runs: pass it as accumulator to simulate! (of a block or a schedule) and read the result with finalize_measurements.

  • Time items (trajectory points, AtTime, Every) record the exact state at their time, the clock included (statistics see pop.t equal to the item's time): before each event, every item due at or before the event's time is recorded with the state before the event, and at a tmax end every item up to tmax.
  • AtSize and When are checked at block start and after each accepted event; AtBlockEnd fires at every block end.
  • At one instant, time items come first (in time order; at equal times the trajectory point, then the triggers in list order), then AtSize/When in list order, then AtBlockEnd.
  • The recorded drug level m is the dose's level at the measurement time.
  • One accumulator can be carried across blocks and schedules: its time grids continue from its first start, each one-shot trigger fires at most once, and the start of a block chained onto one it saw end does not fire again for that state. Grid times that pass while the population is simulated without it are skipped; an AtTime that passes so throws ArgumentError at the next block start.
  • An extinction restart discards what was recorded since the block start.
source
ClonalEvolutionTx.MeasurementSpec — Type
MeasurementSpec(; trajectory_dt = nothing, trajectory_clone_sizes = false,
                triggers = AbstractTrigger[], stats = Any[], samples = Int[],
                sample_seed = 0)

What a MeasurementAccumulator records during simulate!:

  • trajectory_dt: a TrajectoryPoint on the time grid t₀ + k·trajectory_dt, where t₀ is the time at which the accumulator first starts a block (nothing: no trajectory). trajectory_clone_sizes = true adds the living clones' sizes to each point.
  • triggers: when to take a Snapshot: AtTime, AtSize, Every, When, AtBlockEnd.
  • stats: the statistics each snapshot evaluates, with distinct names (see measure).
  • samples, sample_seed: sizes of random samples on which every snapshot also evaluates its statistics, and the base seed of their draws. For the n in samples and a snapshot that will be the i-th of the accumulator, the sample is sample_population(pop, n; seed = derive_seed(sample_seed, i, n)). A snapshot of a population with fewer than n cells (for example at extinction) records (n = n, stats = nothing) for that size: no sample is drawn, and the other sizes keep their seeds.

Throws ArgumentError for a trajectory_dt that is not finite and positive, trajectory_clone_sizes without trajectory_dt, an entry of triggers or stats of the wrong kind, two statistics with the same name, or a sample size below 1.

source

Measurements

ClonalEvolutionTx.Metronomic — Type
Metronomic(base; intervals, N_prog, t_max = Inf, m = 1.0)

Metronomic therapy: FixedDose(m) during each (t_on, t_off) of intervals and no drug otherwise, until progression, extinction or t_max. intervals is a sorted, non-overlapping vector of Tuple{Float64,Float64} with 0 ≤ t_on < t_off, relative to the schedule start. Blocks alternate "metronomic off" and "metronomic on" (zero-length gaps are skipped), followed by a last off block. Counterpart of manuscript_v1's metronomic schedule. t_max is measured from the schedule start. Throws ArgumentError for invalid intervals. With the default t_max = Inf a run that can neither reach N_prog nor die out (for example one held below N_prog by its density dependence) never ends: give a finite t_max unless progression or extinction is certain.

ClonalEvolutionTx.Resistance — Type
Resistance(; ν, α, Δs = 0.0, update = :additive)

Resistance mutations: with probability ν per daughter per division a new α is drawn (α a number in [0, 1] or a univariate distribution; a draw outside [0, 1] throws ArgumentError) and the child gets min(α_drawn, α_parent), so cells only become more resistant. Δs (cost or benefit, either sign) is a number, a distribution, or a function of the drawn α; it is applied to s with the update rule of Drivers, even if the min rule leaves α unchanged.

ClonalEvolutionTx.Stabilising — Type
Stabilising(base; N_stable, N_prog, t_max, m_max = 1.0)

Stabilising therapy: "stabilising: reduce" (FixedDose(m_max)) until N falls to N_stable (N ≤ N_stable), then "stabilising: hold" with StabilisingDose(m_max = m_max) until progression, extinction or t_max. ClonalEvolutionTx.hill_number — Method
hill_number(counts, q) -> Float64

Hill number (effective number of types) of order q of the distribution p = counts/sum: q = 0 the number of nonzero entries, q = 1 exp(Shannon), q = Inf 1/max p, q = -Inf 1/min p over the nonzero entries (the limits of q → ±∞), otherwise (Σ pᵢ^q)^(1/(1−q)) over the nonzero entries, evaluated in log space so that a large |q| tends to those limits instead of overflowing. All counts zero (an empty distribution) gives 0.0 for every q. Throws ArgumentError for q = NaN or negative counts.

ClonalEvolutionTx.load_population — Method
load_population(path) -> AbstractPopulation

Read a file written by save_population or save_tree: a TreePopulation or CellPopulation according to the file's mode. A file with the wrong magic, an unknown format version, mode or clone-kind code, inconsistent indices, or that ends early gives an ArgumentError naming the file.

ClonalEvolutionTx.sample_population — Method
sample_population(pop, n; seed) -> population

Draw n of the living cells uniformly without replacement and return them as a new population of the same kind. n must satisfy 1 ≤ n ≤ popsize(pop) (ArgumentError otherwise); pop is left untouched.

The draw is a partial Fisher–Yates shuffle of the living-cell order (pop.alive or pop.cells) driven by StableRNG(seed); it is a pure function of (pop, n, seed), stable across Julia versions. For one seed, draws at different n are nested: the n-draw is the first n cells of any larger draw. Distinct draws need distinct seeds (derive_seed makes them). The sampled cells are in draw order.

A TreePopulation yields the induced tree: the sampled leaves plus every ancestor of a sampled leaf, unary nodes kept (not collapsed), and the root of each sampled lineage stays a root (so the founder is the root, not the sample's MRCA, and a forest stays a forest). Ids, birth times, clones and mutation counts are those of the source cells, hence burdens and divisions of the sampled cells equal their full-tree values and every statistic applies unchanged. A CellPopulation yields the drawn cells, copied as values.

Either way the clone table keeps every clone (also those with no cell in the sample) with sizes recounted over the sample, and t, m, clonal_mutations, next_id, the neutral stream and the log are copied.

save_population(path, pop::AbstractPopulation) -> path

ClonalEvolutionTx.save_tree — Method
save_tree(path, pop::TreePopulation, node::CellNode) -> path

Write the subtree under node (a cell of pop.tree) to path as a single-root tree-mode population file (the format of save_population). node becomes the root and carries every neutral mutation on its path from the founder: in the file its neutral count is set to its total, so the mutations inherited from above count at k = n in the site frequency spectrum and are part of clonal_mutations and of every cell's mutations_per_cell, which equal the source cells' burdens. divisions_per_cell of the loaded file counts the divisions from the subtree root. ClonalEvolutionTx.sfs_hill_number — Method
sfs_hill_number(sfs, q; frequencies = :normalised) -> Float64

Hill number of order q of the mutations in a site-frequency spectrum (sfs[k] mutations carried by k cells, N = length(sfs)), under one of two definitions of the frequencies:

  • :normalised (default): p = k/A with A = Σ k·Sₖ, a proper distribution; ∞D = A/k_max and ₋∞D = A/k_min.
  • :cell_fraction: p = k/N, as in the v1 papers; the p sum to the mean burden, so this is not a proper Hill family. q = 1 is exp(−Σ Sₖ (k/N) ln(k/N)), ∞D = N/k_max and ₋∞D = N/k_min.

k_max and k_min are the largest and smallest k with Sₖ > 0; q = ±Inf are the limits of q → ±∞, which large finite |q| approach (the power sum is evaluated in log space).

q = 0 is the number of mutations ΣSₖ in both. With m̄ = A/N: ²D_norm = m̄²·²D_cell and H₁,norm = H₁,cell/m̄ + ln m̄. An SFS without mutations gives 0.0 for every q. Throws ArgumentError for another frequencies or q = NaN.

ClonalEvolutionTx.simulate! — Function
simulate!(pop, block::BirthDeathBlock, rng = Xoshiro(); accumulator = nothing) -> pop

Simulate block on the population pop in place, continuing its clock, cells and clone table, and append one BlockSummary (label, start and end time, end reason, ticks, accepted events, restarts, dose, final drug level) to pop.log.

The process is simulated exactly, by thinning against a bound on the total rate of the living clones. At the start and after every event the block ends, in this order of checks, when the population is extinct (:extinct), N ≥ stop_above (:above), N ≤ stop_below (:below) or stop(pop) returns true (:stopped). tmax is an absolute time: if the next event would fall after it, the clock is set to exactly tmax and the block ends (:tmax); discarding that event is exact because waiting times are memoryless. If no event can occur (all rates zero), the clock jumps to tmax, or an ErrorException is thrown when tmax = Inf.

With restart_on_extinction = true, a population that dies out is restored to its state at the start of the block and simulated again with the continuing random stream, until a stop other than extinction ends the block (a population certain to die out restarts forever). The restarts are counted, and the ticks and accepted events of all attempts are added up.

All randomness of the dynamics comes from rng; the neutral-mutation stream is seeded from it at the block start. accumulator (a MeasurementAccumulator) collects measurements during the run; nothing records nothing.

Throws ArgumentError if tmax lies before pop.t, if a rate is negative or not finite (β(s), δ(s), B(N), C(N) or D(m)), or if restart_on_extinction is set for an empty population.

ClonalEvolutionTx.write_newick — Method
write_newick(io::IO, pop::TreePopulation; branch_lengths = :divisions)
write_newick(path::AbstractString, pop::TreePopulation; branch_lengths = :divisions)

Write the genealogy of the living cells as Newick, one tree per root (founder) and one line per tree, each ending in ; and a newline (an empty population writes nothing). Leaves are labelled by cell id; chains of single-child nodes are collapsed. Each tree is rooted at the most recent common ancestor of the cells below its founder, and the root's branch length is its stem, from the founder to that ancestor. branch_lengths is :divisions or :time (anything else is an ArgumentError):

  • :divisions: a branch length is the number of divisions along the collapsed chain, and the stem the divisions from the founder to the ancestor, e.g. (4:2,8:3):0; or (8:1,9:1):2;.
  • :time: every node sits on the time axis, a branching node at its division (the birth time of its daughters) and a leaf at pop.t, so a branch length is the time between a node and the division above it, and the stem is the ancestor's division time minus the founder's birth time. The tree is ultrametric (every root-to-leaf length is pop.t minus the founder's birth time), and the length from a leaf up to the common ancestor of two cells is their coalescence_times entry.

A founder with a single living cell gives (17:0):d;, where d is its stem: the divisions from the founder to the cell, or pop.t minus the founder's birth time. Written iteratively, so deep trees are safe.
